# Getting help

- **Questions and ideas:** use [GitHub Discussions](https://github.com/OmegaSoftDLL/omegadesk/discussions).
- **Bugs:** [open an issue](https://github.com/OmegaSoftDLL/omegadesk/issues/new/choose) using the bug report form.
- **Security problems:** follow [SECURITY.md](SECURITY.md). Do not post them publicly.

OmegaDesk is in early development, so there is no commercial support yet.
